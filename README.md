# 🎬 Video Merger Bot

بوت تجميع مقاطع بجودة CRF 18 + 30fps سموذ + حماية FloodWait كاملة.

## 🚀 النشر على Railway
1. ارفع الملفات على GitHub
2. Railway → New Project → Deploy from GitHub
3. Variables:
   - `API_ID`
   - `API_HASH`
   - `BOT_TOKEN`

## 📋 الأوامر
- `/start` - البداية
- `/show` - عرض القائمة
- `/merge` - دمج المقاطع
- `/clear` - مسح القائمة
